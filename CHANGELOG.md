# Changelog

## [1.0.0] - 2026-09-12

### Added
- Initial release
- Support for `flux`, `klein`, and `zimage` models
- Authenticated API support via `POLLINATIONS_API_KEY`
- Legacy free fallback endpoint (no key required)
- Automatic fallback on API failure
- Aspect ratio support: `square`, `landscape`, `portrait`
- Configurable seed for reproducible generations
